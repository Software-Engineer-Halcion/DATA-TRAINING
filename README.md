# Data Training & Accident Severity Prediction

A Python-based data science project focused on exploring, preprocessing, and analyzing road traffic accident data to understand the factors associated with accident severity.

## 📌 Project Overview

This project was developed as part of my data science programming coursework. It uses a real-world road traffic accident dataset to practice the complete data analysis and machine learning workflow.

The project covers data preparation, exploratory analysis, feature processing, model training, and evaluation.

## 🎯 Objectives

* Explore and understand a real-world accident dataset.
* Clean and preprocess the data for machine learning.
* Identify patterns and factors associated with accident severity.
* Train machine learning models to predict accident severity.
* Evaluate the performance of the trained model.
* Gain practical experience working with Python and data science tools.

## 📊 Dataset

The project uses the **Road Traffic Accident (RTA) dataset**, originally obtained from Kaggle.

The dataset contains information about road traffic accidents and includes variables that can be used to analyze and predict accident severity.

The dataset is included in this repository as:

`RTA Dataset.csv.zip`

## 🔬 Data Science Workflow

The project follows these major stages:

1. **Data Collection**

   * Obtained the road traffic accident dataset from Kaggle.

2. **Data Exploration**

   * Examined the structure and characteristics of the dataset.
   * Identified relevant variables and patterns.

3. **Data Preprocessing**

   * Prepared the dataset for analysis and machine learning.
   * Handled categorical and numerical data appropriately.

4. **Feature Engineering**

   * Selected and prepared relevant features for prediction.

5. **Model Training**

   * Split the dataset into training and testing sets.
   * Trained machine learning models using Scikit-learn.

6. **Model Evaluation**

   * Evaluated model performance using appropriate classification metrics.

7. **Analysis**

   * Interpreted the results and identified factors associated with accident severity.
